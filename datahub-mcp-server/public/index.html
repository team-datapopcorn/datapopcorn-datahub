DataPopcorn Hub

개인 데이터 소스들을 MCP(Model Context Protocol) 툴로 노출하는 서버. Claude 같은 AI 에이전트가 이 서버에 붙으면 아래 툴을 직접 호출해서 실시간 데이터를 가져올 수 있음.

이게 뭐임

보통 대시보드는 데이터를 화면에 박제해서 보여주는데, 이건 반대. 데이터를 API 형태로 열어두고 AI 에이전트가 필요할 때마다 직접 호출해서 최신 값을 가져오게 만든 서버임. 새 데이터 소스가 생기면 이 서버에 툴이 하나씩 늘어나는 구조 — 아래 목록은 지금 이 페이지를 여는 순간 서버에 직접 물어봐서 보여주는 실시간 목록이라, 새 툴이 추가되면 배포되는 즉시 여기도 같이 바뀜.

연결하는 법

터미널에서 한 줄:

claude mcp add --transport http datahub https://api.datapopcorn.ai/mcp

설정 > 커넥터 > 커넥터 추가에서 아래 URL 입력:

https://api.datapopcorn.ai/mcp

연결 후 대화창에 그냥 이렇게 물어보면 됨:

datahub guide 보여줘

현재 등록된 데이터 소스, 각 툴 사용법, 예시 질문을 안내해줌. 그 다음부턴 자연어로 편하게 요청하면 Claude가 알아서 적절한 툴을 골라 씀.

인증 없이 공개 — 지금은 공개 데이터(NEIS)만 서빙 중이라 그렇고, 개인 데이터 소스가 붙으면 인증이 생김.
