# business-docs/

AI 도구 교육(Claude Code 등)의 **업무 문서 실습 세트**. 다른 폴더(`csv/`, `txt/`, `pdf/` …)는 파일 타입별로 묶여 있지만, 이 폴더만 예외로 **수강생 작업 폴더 구조를 그대로** 담는다.

교안의 프롬프트가 `@references/지난제안서.md`, `@drafts/파트너미팅_회의록.txt` 처럼 **경로째** 파일을 가리키기 때문이다. 타입별로 흩어 두면 수강생이 파일을 다시 옮겨야 하고, 초보자는 거기서 막힌다.

## 쓰는 법

수강생은 폴더 내용을 자기 작업 폴더에 통째로 복사한다. Claude Code에게 그대로 시켜도 된다.

```
https://github.com/team-datapopcorn/datapopcorn-datahub/tree/main/public-dataset/business-docs
여기 파일들을 내 작업 폴더에 그대로 넣어줘. references, drafts, data 폴더 구조는 유지해줘.
```

복사 후 작업 폴더 모습:

```
내작업폴더/
├─ references/   회사 양식·참고 문서
├─ drafts/       회의록·초안
├─ data/         분석용 CSV
└─ research/     (수업 중 생성)
```

## 주의

- **전부 가상(Mock)이다.** 회사명(주식회사 세이프칩), 인물명, 고객사명, 금액, 날짜, 인증 번호 모두 지어낸 값이다. 실존 기업·인물과 무관하다.
- 실제 고객 정보·계약 자료·미공개 기술 정보는 이 폴더에 넣지 않는다.
- 문서는 **구조가 뚜렷하게** 써 두었다. 구조 추출 실습이 성공 체험이 되어야 하기 때문이니, 항목 제목을 흐리게 고치지 말 것.
