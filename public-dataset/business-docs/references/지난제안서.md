## 1. 제안 배경

대한전력계량은 2027년부터 신규 공급하는 스마트미터 전량에 보안 기능을 넣어야 합니다.
2025년 개정된 계량기 보안 요구사항에서 기기별 고유 인증이 의무화됐기 때문입니다.

현재 대한전력계량이 쓰는 방식은 공장에서 열쇠 파일을 만들어 기기 메모리에 넣는 방식입니다.
이 방식은 두 가지 문제가 있습니다.

1. 열쇠 파일이 공장 서버에 남아 있어 유출 위험이 있습니다.
2. 기기 폐기 시 인증서를 무효화하는 절차가 기록으로 남지 않습니다.

## 2. 현황 분석

| 항목 | 현재 | 요구 수준 |
|---|---|---|
| 기기별 고유 인증 | 없음 (모델 단위 공용 열쇠) | 기기 1대당 1개 |
| 열쇠 보관 위치 | 공장 서버 | 기기 내부 |
| 인증서 회수 절차 | 수기 관리 | 시스템 기록 |
| 연간 생산 물량 | 약 42만 대 | 동일 |

## 3. 제안 내용

### 3-1. 보안칩 SC-100 적용

기기마다 서로 다른 고유값을 칩 안에서 직접 만들어 냅니다. 열쇠 파일을 외부에 두지 않으므로
공장 서버 유출 위험이 사라집니다.

### 3-2. 인증 관리 소프트웨어 SafeManager 연동

생산 라인에서 발급한 인증서를 한 화면에서 조회하고, 폐기 기기의 인증서를 무효화합니다.
무효화 이력은 5년간 보관됩니다.

### 3-3. 생산 라인 적용 컨설팅

기존 조립 라인에 칩 삽입 공정을 넣기 위한 회로 변경안과 시험 항목을 함께 설계합니다.

## 4. 도입 절차

| 단계 | 기간 | 주요 활동 | 고객 준비 사항 |
|---|---|---|---|
| 1. 사전 검토 | 3주 | 현재 회로도 검토, 적용 범위 확정 | 회로도, 생산 공정도 제공 |
| 2. 시제품 제작 | 6주 | 보안칩 적용 시제품 20대 제작 | 시제품용 자재 제공 |
| 3. 시험 | 4주 | 동작 시험, 보안 요구사항 적합성 확인 | 시험 설비 사용 협조 |
| 4. 양산 적용 | 8주 | 라인 세팅, 초도 물량 생산 | 라인 정지 일정 조율 |
