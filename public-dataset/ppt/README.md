# ppt/

PowerPoint 실습용 폴더. AI 도구 교육 시 슬라이드 읽기·요약·재생성 연습에 사용.

## 넣을 파일

- 여러 슬라이드로 구성된 pptx 파일 (표지·목차·본문·연락처)
- 이미지가 많이 박힌 디자인 템플릿형 덱
- 표/차트/발표자 노트가 있는 실무형 보고 덱

## 파일 목록

| 파일 | 내용 | 용량 |
|---|---|---|
| `creative_brief_deck.pptx` | 크리에이티브 브리프 템플릿. 10슬라이드, 사진 16장, 텍스트는 전부 Lorem ipsum. 표·차트·발표자 노트 없음 | 5.3MB |

`creative_brief_deck.pptx` 슬라이드 구성:

```
1  표지 (CREATIVE BRIEF)
2  목차 (6개 섹션)
3  01 Project Overview
4  02 Target Audience   — Age / Client / Location 항목형
5  03 Social Media      — 이미지 전면
6  03 Social Media      — 본문
7  04 Deliverables
8  05 Visual Style      — 본문
9  05 Visual Style      — 이미지 전면
10 06 Contact Us
```

## 연습 예시

- python-pptx로 슬라이드별 텍스트 추출 → 목차/요약 만들기
- Lorem ipsum 자리에 우리 회사 내용을 채워 새 덱 생성
- 슬라이드에서 이미지만 뽑아내기 (`ppt/media/`)
- pptx → 마크다운/PDF 변환
- 디자인(레이아웃·색)은 두고 텍스트만 한국어로 교체
- 용량 큰 덱의 내장 이미지 재압축해서 파일 줄이기

## 주의

- **원본은 Canva 무료 템플릿**을 내려받은 것이다. 실습·학습 용도로만 쓰고, 이 파일을 상용 배포물이나 판매 콘텐츠에 그대로 넣지 말 것. Canva 콘텐츠 라이선스는 템플릿 파일 자체의 재배포를 제한한다.
- 저장소에 넣기 전 내장 JPEG을 **장변 1920px·품질 80**으로 재인코딩했다(39.4MB → 5.3MB). 슬라이드 레이아웃·텍스트·구성은 원본 그대로이고, 파트 개수도 원본과 동일(75개)하다. 화면 투사에는 차이 없지만 원본 해상도가 필요하면 Canva에서 다시 받을 것.
- 텍스트는 Lorem ipsum이라 **요약·번역 실습에는 부적합**하다. 구조 추출·형식 변환·이미지 처리 실습용이다. 한국어 본문이 필요한 실습은 `business-docs/` 를 쓴다.
